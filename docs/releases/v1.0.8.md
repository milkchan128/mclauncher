# mlkc Client 1.0.8

배경 그림을 단순하고 깔끔한 그림으로 바꿨습니다.

- 메인 화면, 다른 화면, 설치 화면에 새 배경을 적용했습니다. 보라색 저녁 하늘, 가운데 해, 겹친 산과 마인크래프트 느낌의 계단 지형만으로 구성했습니다.
- 이전 연필화 배경은 설치 파일에서 빠져 설치 파일 크기가 약 113MB에서 약 107MB로 줄었습니다.

화면 구성과 동작은 바뀌지 않았습니다. 기존 사용자는 자동 업데이트로 받습니다.

테스트 24개·ESLint·Windows 빌드와 설치 프로그램 자체 검사를 통과했습니다. 메인 화면은 정적 렌더링으로, 설치 화면은 미리보기 이미지로 확인했습니다.

실제 설치 과정을 처음부터 끝까지 진행해 보지는 않았습니다. 설치 파일은 코드 서명되지 않았습니다.
