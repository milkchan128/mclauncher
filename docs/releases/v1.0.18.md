# mlkc Client 1.0.18

Java를 따로 설치하지 않아도 게임을 시작할 수 있습니다.

- 게임 시작을 눌렀을 때 PC에 Java 17이 없으면 묻지 않고 런처 전용 Java 17(Temurin, 약 190MB)을 자동으로 받아 설치한 뒤 이어서 게임을 시작합니다.
- 이전에는 "호환되는 Java가 설치되지 않음" 창에서 "수동 설치"를 누르면 실행이 그대로 멈췄습니다. 이 확인 창과 수동 설치 안내를 없앴습니다.
- Java 다운로드에 실패하면 실행 화면이 멈춘 채로 남지 않고 "Java를 설치하지 못했습니다" 안내가 나옵니다. 인터넷 연결을 확인한 뒤 게임 시작을 다시 누르면 됩니다.
- Java 파일이 손상됐을 때 엉뚱한 오류가 나던 문제도 고쳤습니다.

기존 사용자는 자동 업데이트로 받습니다.

테스트 25개·ESLint·Windows 빌드와 설치 프로그램 자체 검사를 통과했고, Java 17 다운로드 정보 조회를 확인했습니다. Java가 없는 PC에서 실제로 받아 설치하는 과정은 아직 확인하지 않았습니다. 설치 파일은 코드 서명되지 않았습니다.
