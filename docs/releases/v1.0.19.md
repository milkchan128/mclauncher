# mlkc Client 1.0.19

로그인 없이 바로 메인 화면으로 들어갑니다.

- 클라이언트를 켜면 로그인·환영 화면 없이 바로 메인 화면이 나옵니다.
- **게임 시작**을 눌렀을 때 로그인된 계정이 없으면 Microsoft 로그인 화면으로 이동합니다. 로그인한 뒤 게임 시작을 다시 누르면 됩니다. 로그인 화면에서 취소하면 메인 화면으로 돌아갑니다.
- 저장된 계정이 있으면 게임 시작을 누를 때 계정을 확인하고 필요하면 자동으로 갱신합니다. 확인에 실패해도 계정은 지우지 않으며, 다시 시도·다시 로그인·다른 저장된 계정 선택 중에서 고를 수 있습니다.
- 설정에서 마지막 계정을 로그아웃해도 로그인 화면으로 넘어가지 않고 설정 화면에 머뭅니다.
- Microsoft 로그인이 테스트용 MRSLauncher 클라이언트 ID 대신 밀튜디오 전용 클라이언트 ID를 사용합니다.

기존 사용자는 자동 업데이트로 받습니다.

테스트 25개·ESLint·Windows 빌드와 설치 프로그램 자체 검사를 통과했습니다. 밀튜디오 전용 클라이언트 ID로 실제 Microsoft 로그인을 해 보지는 않았습니다. 설치 파일은 코드 서명되지 않았습니다.
