# mlkc Client 1.0.12

게임을 시작하면 마인카트가 진행 상황을 알려 줍니다.

- **게임 시작**을 누르면 버튼이 빨간 **실행 중지** 버튼으로 바뀝니다. 서버 버튼은 실행이 끝날 때까지 숨깁니다.
- 아래쪽 진행 막대 대신, 마인카트가 빠르게 달리고 스티브 머리 위 말풍선에 지금 하는 일과 진행률을 보여 줍니다. 게임이 켜지면 말풍선은 "게임 실행 중이에요"로 바뀌고 카트는 원래 속도로 돌아옵니다.
- **실행 중지**를 누르면 "정말로 중지하시겠어요?"라고 한 번 더 묻습니다. 중지하면 준비 작업(Forge 설치, 파일 검사·다운로드)이나 실행 중인 게임을 끝내고 처음 화면으로 돌아갑니다. 이미 받은 파일은 다음 실행 때 다시 사용합니다.
- 오류·확인 창을 Windows 11 대화 상자 모양으로 바꿨습니다.

기존 사용자는 자동 업데이트로 받습니다.

테스트 24개·ESLint·Windows 빌드와 설치 프로그램 자체 검사를 통과했습니다. 중지 버튼, 말풍선, 확인 창은 정적 렌더링 화면으로 확인했습니다.

실제 계정으로 게임을 실행하고 중지해 보지는 않았습니다. Java 자동 다운로드 중에 중지하면 다운로드는 뒤에서 끝까지 진행되고 게임은 시작하지 않습니다. 설치 파일은 코드 서명되지 않았습니다.
