# mlkc Client 1.0.14

Microsoft 로그인 테스트용 임시 버전입니다.

- Microsoft 로그인에 MRSLauncher 기본 클라이언트 ID를 임시로 사용합니다. 테스트가 끝나면 밀튜디오 전용 ID로 되돌릴 예정입니다.
- 이전 버전에서 로그인한 계정은 자동 갱신이 되지 않을 수 있습니다. 이 경우 **다시 로그인**을 한 번 눌러 주세요. 저장된 계정은 삭제되지 않습니다.

기존 사용자는 자동 업데이트로 받습니다.

테스트 24개·ESLint·Windows 빌드와 설치 프로그램 자체 검사를 통과했습니다. 실제 Microsoft 로그인은 확인하지 않았습니다. 설치 파일은 코드 서명되지 않았습니다.
