# mlkc Client 1.0.6

메인 화면을 새 디자인으로 바꿨습니다.

- 왼쪽 아이콘 메뉴에서 홈·소식·모드·계정·설정으로 바로 이동합니다. 모드 버튼은 설정의 모드 탭을 엽니다.
- 배경 그림을 화면 가득 보여주고, 맨 위 공지 바에 최신 공지 제목을 표시합니다. 바로가기를 누르면 소식 패널에서 공지를 엽니다. 등록된 공지가 없으면 안내 문구만 표시합니다.
- 아래 띠에 서버 이름·주소·접속 인원·Minecraft·Forge 버전을 표시합니다. 게임을 시작하면 같은 자리에 진행률이 나타납니다.
- 창 상단 막대를 Windows 11 형태로 바꿨습니다.
- 화면 진입, 버튼, 진행률에 애니메이션을 넣었습니다. Windows의 애니메이션 효과를 끄면 움직이지 않습니다.
- Mojang 서비스 상태 표시를 없앴습니다.
- Microsoft 로그인에 밀튜디오 전용 클라이언트 ID를 사용합니다.

테스트 24개·ESLint·Windows 빌드를 검증했습니다. 메인 화면은 정적 렌더링으로 기본·게임 준비 중·소식 열림 상태를 확인했습니다.

실제 Microsoft 계정 로그인과 게임 접속은 미검증입니다. 설치 파일은 코드 서명되지 않았습니다.
