# mlkc Client 1.0.2

- 설치 화면·앱 소개·환영 문구·서버 표시 이름에서 모드팩 이름을 제거하고 밀튜디오 브랜드로 통일했습니다. 내부 다운로드 구성과 출처 정보는 유지합니다.
- 실행 버튼을 **게임 시작**으로 표시하고 필요한 모드를 자동 설치한 뒤 실행한다는 안내를 추가했습니다.
- 기존 자동 설치 기능은 Microsoft 로그인 후 **게임 시작**을 누르면 실행됩니다. 정상 파일은 재사용하고 누락되거나 손상된 파일만 다시 받습니다. 모드를 직접 찾아 설치할 필요가 없습니다.

## 설치와 업데이트

`mlkc-Client-setup-1.0.2.exe`를 실행하세요. 1.0.1에서는 자동 업데이트로 받을 수 있습니다. 로고에서 멈추는 1.0.0은 업데이트가 초기화되지 않으므로 설치 파일을 직접 실행해야 합니다. 기존 계정·게임 데이터를 삭제할 필요는 없습니다.

## 검증

테스트 15개와 ESLint, Windows 빌드를 검증했습니다. 실제 다운로드 엔진으로 모드 파일의 자동 설치·정상 파일 재사용·손상 파일 복구·사용자 파일 보존을 확인했습니다. 시작 화면 회귀 테스트와 설치 디자인·배포 파일 해시도 확인했습니다.

누락·손상·보존 시나리오는 로컬 HTTP 서버의 테스트 파일로 검증했고, 공식 CDN에서도 실제 모드 파일 두 개를 내려받아 해시를 확인했습니다. 실제 Microsoft 계정 인증 완료·전체 게임 실행·서버 접속은 검증하지 않았으며 설치 파일은 코드 서명되지 않았습니다.
