# mlkc Client 1.0.16

게임을 준비하는 동안 지금 어떤 작업을 하고 있는지 직접 볼 수 있습니다.

- 게임을 시작하면 **실행 중지** 버튼 왼쪽에 **콘솔** 버튼이 생깁니다.
- 콘솔 버튼을 누르면 터미널 같은 창이 열리고, 파일 확인·다운로드·Forge 설치·게임 출력 같은 런처 로그가 실시간으로 표시됩니다.
- 경고는 노란색, 오류는 빨간색으로 표시하며 최근 2000줄까지 보관합니다. 로그는 드래그해서 복사할 수 있습니다.
- 창은 닫기 버튼, Esc 키, 창 바깥을 눌러 닫을 수 있습니다.

기존 사용자는 자동 업데이트로 받습니다.

테스트 25개·ESLint·Windows 빌드와 설치 프로그램 자체 검사를 통과했습니다. 실제 게임 실행 중에 콘솔 창을 열어 보지는 않았습니다. 설치 파일은 코드 서명되지 않았습니다.
