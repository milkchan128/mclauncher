# mlkc Client 1.0.1

시작할 때 물방울 로고에서 멈추고 로그인 화면으로 넘어가지 않던 문제를 수정했습니다.

설치본에 포함된 모드팩 구성을 빠르게 읽으면 화면의 이벤트 리스너가 준비되기 전에 완료 신호를 보내는 문제가 있었습니다. 화면이 준비된 뒤 신호를 전달하도록 수정했습니다. 설치 화면, Microsoft 로그인 방식, 기존 계정·게임 설정은 유지합니다.

## 설치

**1.0.0에서 로고 화면에 멈춘 경우 `mlkc-Client-setup-1.0.1.exe`를 직접 다운로드해 실행하세요.** 멈춘 상태에서는 자동 업데이터도 초기화되지 않으므로 이번 수정본은 수동으로 설치해야 합니다. 기존 계정이나 게임 데이터를 삭제할 필요가 없습니다.

## 검증

- 모드팩 구성이 화면보다 먼저 준비되는 상황을 재현하는 회귀 테스트를 추가했습니다. 구성 로딩의 성공·실패와 화면의 준비 시점을 각각 검증합니다.
- 실제 Electron에서 별도의 테스트 프로필로 첫 실행과 재실행을 확인하고, 로고가 사라져 Microsoft 로그인 화면에 도달하는지 검사합니다.
- 테스트 14개, ESLint, Windows 빌드 및 최종 배포 파일의 해시를 검증했습니다.

실제 Microsoft 계정 인증 완료와 게임 서버 접속은 검증하지 않았으며 설치 파일은 코드 서명되지 않았습니다.
