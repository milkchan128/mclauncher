# mlkc Client 1.0.15

게임 안 서버 목록에 서버가 미리 들어가 있습니다.

- 게임을 시작하면 **멀티플레이** 목록 맨 위에 "대충모인팀 Society: Sunlit Valley" 서버가 자동으로 추가됩니다.
- 직접 추가한 다른 서버는 그대로 둡니다. 같은 주소가 이미 있으면 중복으로 추가하지 않습니다.
- 서버 목록 파일이 손상되어 읽을 수 없으면 파일을 건드리지 않고, 게임 실행은 그대로 진행합니다.
- Microsoft 로그인은 1.0.14와 같이 테스트용 MRSLauncher 기본 클라이언트 ID를 계속 사용합니다.

기존 사용자는 자동 업데이트로 받습니다.

테스트 25개·ESLint·Windows 빌드와 설치 프로그램 자체 검사를 통과했습니다. 실제 게임에서 서버 목록을 열어 보지는 않았습니다. 설치 파일은 코드 서명되지 않았습니다.
