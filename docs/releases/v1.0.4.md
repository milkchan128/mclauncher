# mlkc Client 1.0.4

Windows에서 로그인 전에 자동 업데이트를 완료하도록 변경했습니다.

- 앱을 시작하면 먼저 새 버전을 확인합니다. 최신 버전일 때만 환영·로그인·런처 화면으로 넘어갑니다.
- 새 버전이 있으면 다운로드 진행률을 표시하고, 파일 검증이 끝난 뒤 무인 설치·재실행을 요청합니다. 업데이트 중에는 기존 버전으로 로그인하거나 게임을 시작하지 않습니다.
- 확인·다운로드·설치 요청에 실패하면 로그인 화면 대신 **다시 시도 / 종료**를 표시합니다. 네트워크 연결이 필요합니다.
- 모드팩 구성 로딩과 독립적으로 업데이트를 확인하므로 구성 로딩 오류가 있어도 업데이트를 시도할 수 있습니다.
- 앱 사용 중의 30분 주기 확인과 설정의 수동 업데이트 확인은 유지합니다.

이 동작은 **1.0.4부터 적용**됩니다. 이전 버전에서는 `mlkc-Client-setup-1.0.4.exe`를 한 번 실행하거나 기존 업데이트를 받은 뒤 재시작하세요. 로고에서 멈추는 1.0.0은 직접 설치해야 합니다. 계정·게임 데이터는 보존됩니다.

테스트 20개·ESLint·Windows 빌드를 검증했습니다. 실제 Electron에서 로그인 차단·진행률·오류·재시도·최신 버전 진입을 확인했습니다. 실제 NSIS 업데이터로 다운로드·SHA-512 검증과 무인 설치·재실행 인수를 검증했으며 테스트에서는 설치 실행을 대체했습니다.

실제 설치 교체부터 새 버전 실행까지의 전체 과정과 계정 인증 완료·게임 접속은 미검증입니다. 설치 파일은 코드 서명되지 않았습니다.
