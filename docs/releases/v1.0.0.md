# mlkc Client 1.0.0

밀튜디오 클라이언트의 첫 정식 Windows x64 릴리스입니다.

- 앱 이름과 버전을 `mlkc Client 1.0.0`으로 적용했습니다.
- 밀튜디오 로고와 직접 제작한 연필화 배경을 사용합니다.
- 설치 화면 전체를 전용 디자인으로 바꾸고, 환영 → EULA 동의 → 설치 대상 → 설치 위치 → 설치 진행 → 완료 단계를 제공합니다.
- EULA 동의 전에는 다음 단계로 이동할 수 없습니다. 단계 사이에는 짧은 페이드·슬라이드 전환을 적용하며 Windows의 애니메이션 설정을 따릅니다.
- Microsoft 로그인만 제공합니다. 기존 Mojang 로그인 기능은 제거했습니다.
- 서버는 `mc.mlkc.kr`, 모드팩은 Society: Sunlit Valley **4.1.5A**입니다. Minecraft **1.20.1**, Forge **47.4.0**, Java **17** 조합을 사용합니다.
- 이후 버전은 이 저장소의 GitHub Releases에서 자동으로 확인·다운로드하고, 재시작하거나 앱을 종료할 때 설치합니다.

## 설치

`mlkc-Client-setup-1.0.0.exe`를 다운로드해 실행하세요. 첫 게임 준비에는 인터넷 연결과 모드팩 다운로드 시간이 필요합니다. 이전 3.0.x 시험 설치본을 사용했다면 이번 버전은 직접 설치해야 합니다.

`.exe.blockmap`과 `latest.yml`은 자동 업데이트용 파일입니다. `.exe.sha256`으로 다운로드한 설치 파일의 SHA-256을 확인할 수 있습니다.

## 검증과 제한

Node.js 24에서 테스트 12개와 ESLint를 통과했고, Windows 설치 파일을 빌드했습니다. 설치 단계와 EULA 동의, 한글·공백 경로, 설치 엔진 전달 인수, 손상 파일 거부, 실제 업데이터의 다운로드·SHA-512 검증을 확인했습니다. 자동화된 설치 검증에는 실제 설치 대신 테스트용 엔진을 사용했습니다.

실제 Microsoft 계정 로그인·게임 실행·서버 접속과 다음 정식 버전으로의 전체 업데이트는 검증하지 않았습니다. 설치 파일은 코드 서명되지 않았습니다. 서버에도 동일한 모드팩 버전이 필요합니다.

MRS Launcher와 Helios Launcher의 출처 및 라이선스를 유지합니다. Minecraft 게임 바이너리는 포함하지 않습니다.
