# mlkc Client 1.0.13

마인카트를 탄 스티브가 더 많은 행동을 합니다.

- 스티브가 몇 초마다 랜덤으로 손 인사, 꾸벅 인사, 만세, 깡충 뛰기, 뒤돌아보기, 사과 먹기 중 하나를 합니다.
- **이스터에그:** 스티브를 누르면 하트가 뿅 나오고 늑대(빨간 목줄), 여우, 검은 고양이 중 하나가 랜덤으로 달려와 카트를 따라 달립니다. 다시 누르면 다른 펫으로 바뀝니다. 펫을 누르면 깡충 뜁니다.
- 게임을 준비하는 동안에는 펫도 카트와 함께 빠르게 달립니다.
- Windows의 애니메이션 효과를 끄면 랜덤 동작은 하지 않고, 펫은 움직이지 않고 카트 뒤에 서 있습니다.

기존 사용자는 자동 업데이트로 받습니다.

테스트 24개·ESLint·Windows 빌드와 설치 프로그램 자체 검사를 통과했습니다. 여섯 가지 동작과 펫 세 종류는 정적 렌더링 화면과 계산된 스타일 값으로 확인했습니다.

실제 앱에서 스티브와 펫을 직접 눌러 보지는 않았습니다. 설치 파일은 코드 서명되지 않았습니다.
