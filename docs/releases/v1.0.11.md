# mlkc Client 1.0.11

메인 화면 배경이 마인카트를 따라 움직입니다.

- 마인카트는 화면 가운데 근처에서 살짝 앞뒤로 흔들리며 달리고, 하늘을 뒤로 산과 지면이 서로 다른 속도로 왼쪽으로 흘러갑니다. 가까울수록 빠르게 지나가 카메라가 카트를 따라가는 느낌을 줍니다.
- 이전보다 달리는 속도를 높였습니다. 레일 침목과 바퀴도 더 빠르게 움직입니다.
- 스티브가 마인카트에 타고 있습니다. 고개를 까딱이고, 가끔 손을 흔듭니다.
- 아래 띠의 로고를 Society: Sunlit Valley 서버 로고로 바꿨습니다.
- 앱과 설치 화면 어디에도 서버 주소를 표시하지 않습니다. 메인 화면 띠, 서버 메뉴, 환영 문구, 설치 화면에서 주소를 뺐습니다. 게임 시작 시 자동 접속은 그대로입니다.
- Windows의 애니메이션 효과를 끄면 배경과 카트는 멈춰 있습니다.

기존 사용자는 자동 업데이트로 받습니다.

테스트 24개·ESLint·Windows 빌드와 설치 프로그램 자체 검사를 통과했습니다. 배경 흐름과 스티브, 서버 로고는 정적 렌더링 화면으로 확인했습니다.

실제 앱에서 오래 켜 두었을 때의 성능은 확인하지 않았습니다. 설치 파일은 코드 서명되지 않았습니다.
