# mlkc Client 1.0.17

일부 PC에서 설치가 끝나지 않던 문제를 고쳤습니다.

- 처음 설치할 때 "설치를 마치지 못했습니다. (-1073741819)" 오류가 나며 설치가 멈추던 문제를 수정했습니다.
- 원인은 설치 엔진(electron-builder 26.6.0의 NSIS 스크립트)이 사용자 프로그램 폴더 경로를 읽을 때 필요한 범위보다 더 많은 메모리를 읽는 버그였습니다. PC의 메모리 배치에 따라 충돌 여부가 달라져 일부 PC에서만 나타났습니다. 이 부분을 고친 electron-builder 26.18.0으로 올렸습니다.
- 앱 기능은 1.0.16과 같습니다.

설치 중 이 오류를 본 분은 새 설치 파일을 받아 다시 설치해 주세요. 기존 사용자는 자동 업데이트로 받습니다.

테스트 25개·ESLint·Windows 빌드와 설치 프로그램 자체 검사를 통과했습니다. 이 PC에서 새 설치 파일로 처음 설치하는 과정은 확인했지만, 오류가 났던 PC에서는 아직 확인하지 않았습니다. 설치 파일은 코드 서명되지 않았습니다.
