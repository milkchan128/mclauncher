# mlkc Client 1.0.5

한 번 로그인한 계정으로 재실행 시 자동 로그인하도록 세션 복원을 개선했습니다.

- 시작 업데이트 확인이 끝나면 저장된 계정을 검증·갱신한 뒤 로그인 창 없이 런처로 들어갑니다.
- 만료된 Microsoft·Minecraft 토큰을 자동 갱신하고 새 refresh token을 저장합니다. 새 refresh token이 생략된 응답에서는 기존 값을 보존합니다.
- 갱신 실패 시 계정을 삭제하지 않습니다. 재시도·다시 로그인·다른 저장 계정 선택을 제공합니다.
- 명시적 로그아웃은 유지하며 게임 실행 직전에도 세션을 확인합니다. Microsoft에서 재인증이 필요한 경우에는 다시 로그인해야 합니다.

테스트 24개·ESLint·Windows 빌드를 검증했습니다. 테스트 계정 정보를 저장한 후 실제 Electron 프로세스를 껐다 켜면서 자동 로그인, 연결 재시도, 다른 계정 선택, 로그아웃 유지까지 확인했습니다. 토큰 갱신과 저장은 테스트 응답으로 검증했습니다.

실제 Microsoft 계정 인증 완료와 게임 접속은 미검증입니다. 설치 파일은 코드 서명되지 않았습니다.
