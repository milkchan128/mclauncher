# mlkc Client 1.0.7

설치 화면을 런처 메인 화면과 같은 디자인으로 바꿨습니다.

- 어두운 창, Windows 11 형태의 최소화·닫기 버튼, 하늘색 주 버튼으로 런처와 색과 모양을 맞췄습니다.
- 왼쪽 그림 카드 아래에 런처와 같은 띠(로고·밀튜디오·mc.mlkc.kr)를 넣었습니다.
- 사용권 계약, 설치 대상, 설치 위치, 진행, 완료 화면의 입력 칸·선택 카드·체크 상자·진행 막대를 같은 스타일로 바꿨습니다.
- 설치 창을 열 때 그림이 천천히 줌 아웃되고 띠가 올라옵니다. 버튼에 마우스를 올리거나 누를 때도 반응합니다. Windows의 애니메이션 효과를 끄면 움직이지 않습니다.
- 설치 오류 문구를 어두운 배경에서도 잘 보이는 색으로 바꿨습니다.

설치 단계, 경로 검증, 업데이트 동작은 바뀌지 않았습니다. 기존 사용자는 자동 업데이트로 받으며, 이때는 설치 화면 없이 설치됩니다.

테스트 24개·ESLint·Windows 빌드와 설치 프로그램 자체 검사를 통과했습니다. 6개 설치 화면은 미리보기 이미지로 확인했습니다.

실제 설치 과정을 처음부터 끝까지 진행해 보지는 않았습니다. 설치 파일은 코드 서명되지 않았습니다.
