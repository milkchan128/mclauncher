# mlkc Client 1.0.10

서버를 옮기고 메인 화면에 작은 움직임을 더했습니다.

- 서버 이름이 **대충모인팀 Society: Sunlit Valley**로, 접속 주소가 **society-sunlit.vultr.sjh.kr**로 바뀌었습니다. 게임을 시작하면 새 주소로 바로 접속합니다. 이미 받은 모드는 그대로 사용합니다.
- 메인 화면 아래 띠 위로 레일이 깔리고, 랜턴을 단 마인카트가 오른쪽으로 계속 달립니다. Windows의 애니메이션 효과를 끄면 카트는 멈춰 있습니다.
- **서버** 버튼을 누르면 Windows 11 메뉴처럼 버튼 위에 서버 목록이 펼쳐집니다. 선택한 서버는 하늘색 막대로 표시되고, Esc나 바깥 클릭으로 닫힙니다.
- 설정의 셰이더팩 드롭다운도 같은 Windows 11 메뉴 모양과 열림 효과로 맞췄습니다.

기존 사용자는 자동 업데이트로 받습니다.

테스트 24개·ESLint·Windows 빌드와 설치 프로그램 자체 검사를 통과했습니다. 마인카트 움직임과 서버 메뉴 모양은 정적 렌더링 화면으로 확인했습니다.

실제 앱에서 서버 메뉴를 클릭·키보드로 조작해 보지는 않았습니다. 설치 파일은 코드 서명되지 않았습니다.
