# mlkc Client 1.0.3

- **설정 → 모드**에서 설치 전에도 서버의 필수 파일 목록을 볼 수 있습니다.
- 아직 파일을 받지 않았거나 파일 크기가 맞지 않으면 **설치되지 않음**, 파일과 크기가 맞으면 **설치됨**으로 표시합니다.
- F5로 설치 상태를 새로고침할 수 있습니다. 필수 파일은 사용자 추가 모드 목록에 중복 표시하지 않으며 사용자 모드는 기존 방식으로 관리할 수 있습니다.
- 모드 다운로드 시점은 그대로입니다. Microsoft 로그인 후 **게임 시작**을 누르면 필요한 파일을 자동으로 받습니다. 설정을 열기만 해서는 다운로드하지 않습니다.

테스트 16개·ESLint·Windows 빌드를 검증했습니다. 실제 Electron에서 설치 전 목록, 파일 생성 후 상태 변경, 사용자 모드와 필수 항목의 중복 제거를 확인했습니다. 기존 로그인 시작 화면과 설치 화면도 검증했습니다.

설치 상태는 파일 유무와 크기를 기준으로 표시하며 해시 검증은 게임 시작 시 수행합니다. 실제 계정 인증 완료·게임 실행·서버 접속은 미검증이며 설치 파일은 코드 서명되지 않았습니다.
