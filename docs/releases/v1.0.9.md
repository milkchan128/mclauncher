# mlkc Client 1.0.9

설정 화면을 메인 화면과 같은 디자인으로 바꿨습니다.

- 왼쪽 메뉴와 둥근 오른쪽 패널로 메인 화면과 같은 틀을 사용합니다. 선택한 메뉴에는 하늘색 표시 막대가 나타나고, 완료 버튼은 하늘색 버튼으로 바뀌었습니다.
- 각 설정 항목을 Windows 11 설정처럼 카드로 묶었습니다. 토글, 입력 칸, 메모리 슬라이더, 드롭다운, 버튼을 같은 스타일로 맞췄습니다.
- 모드 목록의 설치 상태는 초록색, 로그아웃 버튼은 연한 빨간색으로 표시합니다. 선택 모드가 없으면 빈 섹션을 숨깁니다.
- 메뉴가 차례로 나타나고 탭을 바꿀 때 내용이 살짝 올라오는 애니메이션을 넣었습니다. Windows의 애니메이션 효과를 끄면 움직이지 않습니다.

설정 항목과 동작은 바뀌지 않았습니다. 기존 사용자는 자동 업데이트로 받습니다.

테스트 24개·ESLint·Windows 빌드와 설치 프로그램 자체 검사를 통과했습니다. 설정 화면 7개 탭은 정적 렌더링에 예시 데이터를 넣어 확인했습니다.

실제 계정과 데이터로 설정 화면을 열어 보지는 않았습니다. 설치 파일은 코드 서명되지 않았습니다.
